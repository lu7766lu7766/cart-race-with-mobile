# 🏁 3D 卡丁車道具賽車遊戲（Kart Racer — 陸行鳥大賽車風格）

這是一個專為教學設計的 3D 道具競速賽車遊戲專案。
專案以 **Three.js** 搭配原生 Web 街機物理與 Kenney 免費 CC0 3D 素材建置，不需要任何打包工具（Vite/Webpack），只需 Node.js 與瀏覽器即可執行！

本專案現已升級為**陸行鳥大賽車（Chocobo Racing）風格**：具備**自動分割畫面追尾鏡頭**、**甩尾迷你加速（火花集氣）**、**魔石道具升級（Lv1 ~ Lv3）**、**高低起伏賽道與跳台**、以及**四款卡丁車角色被動能力**！

專案分為兩個階段：
- **第一階段（main 分支）**：鍵盤操作、同機分割畫面雙人對戰、電腦 AI 補位、角色能力、道具升級系統與完整自動測試（學生的起始專案）。
- **第二階段（phase2 分支）**：加入 WebSocket、房間管理、HTTPS 自簽憑證，讓手機變成體感方向盤控制器進行多人連線。

## 快速開始（第一階段：鍵盤版）

### 系統需求
- **Node.js** 版本 ≥ 18.0.0
- 現代網頁瀏覽器（Chrome、Edge、Safari、Firefox）

### 啟動步驟
1. 開啟終端機，進入遊戲資料夾：
   ```bash
   cd game
   ```
2. 安裝依賴套件（僅需執行一次）：
   ```bash
   npm install
   ```
3. 啟動本機伺服器：
   ```bash
   npm start
   ```
4. 用瀏覽器打開 [http://localhost:3000](http://localhost:3000) 即可開始遊玩！

## 遊戲操作說明

- **大廳畫面**：
  - **玩家 1 加入**：按鍵盤 **↑**（方向鍵上）
  - **玩家 2 加入**：按鍵盤 **W**
  - **開始比賽**：按 **Enter**（若無人手動加入，預設玩家 1 自動上場，其餘空位由電腦 AI 補滿 4 台）
  - **角色能力**：
    - 🟢 **衝刺手（綠）**：起步快（加速度 ×1.25）、起跑衝刺時間更久（×1.5）
    - 🟣 **極速王（紫）**：極速最快（最高速 ×1.05）、起步稍慢（加速度 ×0.9）
    - 🌸 **甩尾高手（粉）**：甩尾集氣快（集氣速度 ×1.35）、越野不怕草地（草地減速僅剩 ×0.65）
    - 🟠 **重戰車（橘）**：撞不倒（碰撞推開對方 ×2、自己 ×0.5）、被打中恢復快（停頓時間 ×0.6）
- **比賽操作**：
  - **玩家 1**：方向鍵 **↑** 加速、**↓** 煞車/倒退、**← →** 轉向、**右 Shift** 甩尾集氣、**Enter / 小鍵盤 Enter** 施放道具
  - **玩家 2**：鍵盤 **W** 加速、**S** 煞車/倒退、**A D** 轉向、**左 Shift** 甩尾集氣、**空白鍵** 施放道具
  - **起跑衝刺技巧**：在開賽倒數最後 1 秒（顯示「1」之後）按下油門並持續按住，可在開賽時獲得起步火箭加速！若在「3」或「2」太早按住則會空轉受罰。
  - **甩尾與迷你加速**：以高速入彎時按住甩尾鍵，車輪噴出藍色（Lv1）→ 橘色（Lv2）→ 紫色（Lv3）火花，放開甩尾鍵立即獲得迷你衝刺！
  - **魔石道具升級**：持有道具時再拾取道具箱可將道具升級至最高 Lv3（導彈升級為追蹤導彈/多重鎖定、香蕉升級為扇形/巨大香蕉、護盾可撞翻對手）。
  - **跳台落地加速**：在路面楔形跳台飛越滯空超過 0.4 秒，著地時自動獲得著地加速。
  - **比賽中途放棄**：按 **Esc** 鍵可直接返回大廳
- **音效開關**：隨時按 **M** 鍵切換靜音

## 想先玩完成版（手機版）？

如果你想直接體驗手機當作方向盤操控的第二階段完整成品，可透過以下兩種方式切換至 `phase2` 分支：

### 方式 A：會使用 Git
> ⚠️ **重要提醒**：切換分支前，若你有未 commit 的修改，git 會拒絕切換。請先照下方步驟保存進度！

1. 保存自己的修改：
   ```bash
   git add -A
   git commit -m "我的進度"
   ```
   （或先開新分支儲存：`git switch -c my-work && git commit -m "我的進度"`）
2. 切換到第二階段完成版分支：
   ```bash
   git switch phase2
   ```
3. **重新安裝依賴**（第二階段新增了 WebSocket 與 QR Code 等套件，**務必重新安裝**）：
   ```bash
   cd game
   npm install
   ```
4. 啟動伺服器：
   ```bash
   npm start
   ```
5. 電腦開啟大螢幕，手機連上同一個 Wi-Fi 掃描螢幕上的 QR Code 即可連線遊玩！
6. 體驗完畢後切回主分支：
   ```bash
   git switch main
   ```
   （或切回你剛才儲存的分支：`git switch my-work`）

### 方式 B：不會使用 Git
1. 前往 GitHub 專案頁面。
2. 點擊左上角的分支選單，選擇 **`phase2`**。
3. 點擊綠色的 **Code** 按鈕，選擇 **Download ZIP**。
4. 將 ZIP 檔案解壓縮到**另一個全新的資料夾**。
5. 在該資料夾內執行 `cd game && npm install && npm start` 即可遊玩。
