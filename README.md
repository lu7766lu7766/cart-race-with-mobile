# 🏁 3D 卡丁車道具賽車遊戲（Kart Racer — 陸行鳥大賽車風格）

> 🌟 **`main` 分支就是第二階段完整版！**
> 已包含**第二階段完整參考解答**（手機體感方向盤、WebSocket 房間管理、HTTPS 自簽憑證與 QR Code 多人連線對戰）。想從第一階段起始版開始挑戰，請看下方「[學生挑戰：升級為第二階段](#學生挑戰升級為第二階段)」。
>
> 📱 **手機連線體驗步驟**：
> 1. **同一個 Wi-Fi**：確認手機和電腦連接至相同的區網或手機熱點（不可跨網段或開啟客戶端隔離）。
> 2. **安裝套件**：在專案根目錄執行 `npm install`（會自動安裝 `game` 內的套件；第二階段新增了 `ws`、`qrcode`、`selfsigned`，**務必重新安裝**）。
> 3. **啟動伺服器**：在專案根目錄執行 `npm start` 啟動服務。
> 4. **開啟大螢幕**：電腦用瀏覽器打開 [http://localhost:3000](http://localhost:3000)，大廳中央會顯示 4 位數房號與連線 QR Code。
> 5. **手機掃描**：使用手機相機掃描螢幕上的 QR Code（或手動開啟終端機印出的 `https://<區網IP>:3443/controller.html`）。
> 6. **通過憑證警告**（因使用本機自簽 HTTPS 憑證，手機首次開啟會顯示警告，請照下方操作通過）：
>    - **Android (Chrome / Edge)**：點擊「進階」→「繼續前往 <區網IP>（不安全）」。
>    - **iPhone (Safari)**：點擊「顯示詳細資訊」→ 點擊最下方「瀏覽此網站」→ 點擊「瀏覽網站」確認。
> 7. **開始操控**：輸入大螢幕上的 4 位數房號與玩家暱稱，點擊「開始連線」並允許動作與方向感測權限，將手機橫拿即可化身實體方向盤！

這是一個專為教學設計的 3D 道具競速賽車遊戲專案。
專案以 **Three.js** 搭配原生 Web 街機物理與 Kenney 免費 CC0 3D 素材建置，不需要任何打包工具（Vite/Webpack），只需 Node.js 與瀏覽器即可執行！

本專案現已升級為**陸行鳥大賽車（Chocobo Racing）風格**：具備**自動分割畫面追尾鏡頭**、**甩尾迷你加速（火花集氣）**、**魔石道具升級（Lv1 ~ Lv3）**、**高低起伏賽道與跳台**、以及**四款卡丁車角色被動能力**！

專案分為兩個階段：
- **第一階段（tag `phase1-v1`）**：鍵盤操作、同機分割畫面雙人對戰、電腦 AI 補位、角色能力、道具升級系統與完整自動測試（學生的起始專案）。
- **第二階段（`main` 分支，目前版本）**：加入 WebSocket、房間管理、HTTPS 自簽憑證，讓手機變成體感方向盤控制器進行多人連線。鍵盤操作與同機分割畫面仍然可用。

## 快速開始（鍵盤遊玩）

### 系統需求
- **Node.js** 版本 ≥ 18.0.0
- 現代網頁瀏覽器（Chrome、Edge、Safari、Firefox）

### 啟動步驟
1. 開啟終端機，在專案根目錄安裝依賴套件（僅需執行一次，會自動安裝 `game` 內的套件）：
   ```bash
   npm install
   ```
2. 啟動本機伺服器：
   ```bash
   npm start
   ```
   （執行自動測試：`npm test`。以上指令也可以先 `cd game` 再執行，效果相同。）
3. 用瀏覽器打開 [http://localhost:3000](http://localhost:3000) 即可開始遊玩！

## 遊戲操作說明

- **大廳畫面**：
  - **玩家 1 加入**：按鍵盤 **↑**（方向鍵上）
  - **玩家 2 加入**：按鍵盤 **W**
  - **開始比賽**：按 **Enter**（若無人手動加入，預設玩家 1 自動上場，其餘空位由電腦 AI 補滿 4 台）
  - **角色能力**：
    - 🟢 **衝刺手（綠）**：起步快（加速度 ×1.25）、起跑衝刺時間更久（×1.5）
    - 🟣 **極速王（紫）**：極速最快（最高速 ×1.05）、起步稍慢（加速度 ×0.9）
    - 🌸 **甩尾高手（粉）**：甩尾集氣快（集氣速度 ×1.35）、越野不怕草地（草地減速僅剩 ×0.65）
    - 🟠 **重戰車（橘）**：撞不倒（碰撞推開對方 ×2、自己 ×0.5）、被打中恢復快（停頓時間 ×0.6）
- **比賽操作**：
  - **玩家 1**：方向鍵 **↑** 加速、**↓** 煞車/倒退、**← →** 轉向、**右 Shift** 甩尾集氣、**Enter / 小鍵盤 Enter** 施放道具
  - **玩家 2**：鍵盤 **W** 加速、**S** 煞車/倒退、**A D** 轉向、**左 Shift** 甩尾集氣、**空白鍵** 施放道具
  - **起跑衝刺技巧**：在開賽倒數最後 1 秒（顯示「1」之後）按下油門並持續按住，可在開賽時獲得起步火箭加速！若在「3」或「2」太早按住則會空轉受罰。
  - **甩尾與迷你加速**：以高速入彎時按住甩尾鍵，車輪噴出藍色（Lv1）→ 橘色（Lv2）→ 紫色（Lv3）火花，放開甩尾鍵立即獲得迷你衝刺！
  - **魔石道具升級**：持有道具時再拾取道具箱可將道具升級至最高 Lv3（導彈升級為追蹤導彈/多重鎖定、香蕉升級為扇形/巨大香蕉、護盾可撞翻對手）。
  - **跳台落地加速**：在路面楔形跳台飛越滯空超過 0.4 秒，著地時自動獲得著地加速。
  - **比賽中途放棄**：按 **Esc** 鍵可直接返回大廳
- **音效開關**：隨時按 **M** 鍵切換靜音

## 學生挑戰：升級為第二階段

身為學生，你的任務是透過 AI 編碼輔助工具（如 Claude Code 或 Cursor），把第一階段鍵盤版升級為支援手機連線對戰的遊戲！

`main` 分支已經是完成版，所以請先取得第一階段起始版（tag `phase1-v1`）：

### 方式 A：會使用 Git
```bash
git switch -c my-phase2 phase1-v1
cd game
npm install
npm start
```
（第一階段起始版的根目錄還沒有 `package.json`，所以要先 `cd game` 再安裝與啟動。）
這會從第一階段起始版建立你自己的 `my-phase2` 分支，之後的修改都 commit 在這個分支上。想看完成版時，先 commit 自己的進度，再 `git switch main`（記得在專案根目錄重新 `npm install`），看完再 `git switch my-phase2` 切回來。

### 方式 B：不會使用 Git
1. 前往 GitHub 專案頁面，點擊分支選單，切到 **Tags** 分頁並選擇 **`phase1-v1`**。
2. 點擊綠色的 **Code** 按鈕，選擇 **Download ZIP**。
3. 將 ZIP 檔案解壓縮到**一個全新的資料夾**，進入其中的 `game` 資料夾執行 `npm install && npm start`。

### 開始升級

請直接開啟專案根目錄下的 **`plan.md`**，閱讀 **第 7 節「學生用提示詞（第二階段）」**，依序貼上提示詞 1 至 4，讓 AI 帶領你一步一步完成多人體感賽車！
