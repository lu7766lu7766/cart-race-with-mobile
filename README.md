# 🏁 3D 卡丁車道具賽車遊戲（Kart Racer — 陸行鳥大賽車風格）

> 🌟 **遊戲已完成手機體感連線版！**
> 包含手機體感方向盤、WebSocket 房間管理、HTTPS 自簽憑證與 QR Code 多人連線對戰。想繼續讓遊戲更好玩，請看下方「[學生挑戰：持續優化遊戲體驗](#學生挑戰持續優化遊戲體驗15-個提示詞)」。
>
> 📱 **手機連線體驗步驟**：
> 1. **同一個 Wi-Fi**：確認手機和電腦連接至相同的區網或手機熱點（不可跨網段或開啟客戶端隔離）。
> 2. **安裝套件**：在專案根目錄執行 `npm install`（會自動安裝 `game` 內的套件；第二階段新增了 `ws`、`qrcode`、`selfsigned`，**務必重新安裝**）。
> 3. **啟動伺服器**：在專案根目錄執行 `npm start` 啟動服務。
> 4. **開啟大螢幕**：電腦用瀏覽器打開 [http://localhost:3000](http://localhost:3000)，大廳中央會顯示 4 位數房號與連線 QR Code。
> 5. **手機掃描**：使用手機相機掃描螢幕上的 QR Code（或手動開啟終端機印出的 `https://<區網IP>:3443/controller.html`）。
> 6. **通過憑證警告**（因使用本機自簽 HTTPS 憑證，手機首次開啟會顯示警告，請照下方操作通過）：
>    - **Android (Chrome / Edge)**：點擊「進階」→「繼續前往 <區網IP>（不安全）」。
>    - **iPhone (Safari)**：點擊「顯示詳細資訊」→ 點擊最下方「瀏覽此網站」→ 點擊「瀏覽網站」確認。
> 7. **開始操控**：輸入大螢幕上的 4 位數房號與玩家暱稱，點擊「開始連線」並允許動作與方向感測權限，將手機橫拿即可化身實體方向盤！

這是一個專為教學設計的 3D 道具競速賽車遊戲專案。
專案以 **Three.js** 搭配原生 Web 街機物理與 Kenney 免費 CC0 3D 素材建置，不需要任何打包工具（Vite/Webpack），只需 Node.js 與瀏覽器即可執行！

本專案現已升級為**陸行鳥大賽車（Chocobo Racing）風格**：具備**自動分割畫面追尾鏡頭**、**甩尾迷你加速（火花集氣）**、**魔石道具升級（Lv1 ~ Lv3）**、**高低起伏賽道與跳台**、以及**四款卡丁車角色被動能力**！

遊戲功能：
- **鍵盤遊玩**：同機分割畫面雙人對戰、電腦 AI 補位、角色能力、道具升級系統與完整自動測試。
- **手機體感連線**：WebSocket 房間管理、HTTPS 自簽憑證，讓手機變成體感方向盤控制器進行最多 4 人連線對戰。

## 快速開始（鍵盤遊玩）

### 系統需求
- **Node.js** 版本 ≥ 18.0.0
- 現代網頁瀏覽器（Chrome、Edge、Safari、Firefox）

### 啟動步驟
1. 開啟終端機，在專案根目錄安裝依賴套件（僅需執行一次，會自動安裝 `game` 內的套件）：
   ```bash
   npm install
   ```
2. 啟動本機伺服器：
   ```bash
   npm start
   ```
   （執行自動測試：`npm test`。以上指令也可以先 `cd game` 再執行，效果相同。）
3. 用瀏覽器打開 [http://localhost:3000](http://localhost:3000) 即可開始遊玩！

## 遊戲操作說明

- **大廳畫面**：
  - **玩家 1 加入**：按鍵盤 **↑**（方向鍵上）
  - **玩家 2 加入**：按鍵盤 **W**
  - **開始比賽**：按 **Enter**（若無人手動加入，預設玩家 1 自動上場，其餘空位由電腦 AI 補滿 4 台）
  - **角色能力**：
    - 🟢 **衝刺手（綠）**：起步快（加速度 ×1.25）、起跑衝刺時間更久（×1.5）
    - 🟣 **極速王（紫）**：極速最快（最高速 ×1.05）、起步稍慢（加速度 ×0.9）
    - 🌸 **甩尾高手（粉）**：甩尾集氣快（集氣速度 ×1.35）、越野不怕草地（草地減速僅剩 ×0.65）
    - 🟠 **重戰車（橘）**：撞不倒（碰撞推開對方 ×2、自己 ×0.5）、被打中恢復快（停頓時間 ×0.6）
- **比賽操作**：
  - **玩家 1**：方向鍵 **↑** 加速、**↓** 煞車/倒退、**← →** 轉向、**右 Shift** 甩尾集氣、**Enter / 小鍵盤 Enter** 施放道具
  - **玩家 2**：鍵盤 **W** 加速、**S** 煞車/倒退、**A D** 轉向、**左 Shift** 甩尾集氣、**空白鍵** 施放道具
  - **起跑衝刺技巧**：在開賽倒數最後 1 秒（顯示「1」之後）按下油門並持續按住，可在開賽時獲得起步火箭加速！若在「3」或「2」太早按住則會空轉受罰。
  - **甩尾與迷你加速**：以高速入彎時按住甩尾鍵，車輪噴出藍色（Lv1）→ 橘色（Lv2）→ 紫色（Lv3）火花，放開甩尾鍵立即獲得迷你衝刺！
  - **魔石道具升級**：持有道具時再拾取道具箱可將道具升級至最高 Lv3（導彈升級為追蹤導彈/多重鎖定、香蕉升級為扇形/巨大香蕉、護盾可撞翻對手）。
  - **跳台落地加速**：在路面楔形跳台飛越滯空超過 0.4 秒，著地時自動獲得著地加速。
  - **比賽中途放棄**：按 **Esc** 鍵可直接返回大廳
- **音效開關**：隨時按 **M** 鍵切換靜音

### 第 1 題：轉向手感設定（🎯 陀螺儀 ★）

```
你是我的程式老師，我是初學者。請先閱讀 game/public/js/controller.js 的 processTilt()，了解目前手機傾斜角度怎麼換算成 steer（5 度死區、40 度滿舵、0.4n + 0.6n² 曲線）。
請在手機方向盤畫面加一個「⚙️ 手感」小按鈕，打開設定面板，讓玩家調整：
1. 靈敏度：低 / 中 / 高，分別對應滿舵角度 55 / 40 / 28 度
2. 死區：0～10 度的滑桿（預設 5）
3. 轉向曲線：「線性」或「平滑」（平滑就是目前的 0.4n + 0.6n²）
4. 面板上即時顯示目前的傾斜角度與換算出的 steer 數值（-1.00 ～ +1.00），讓玩家邊轉邊調
設定存在 localStorage（讀寫要包 try/catch），下次打開自動套用。把這些數值抽成常數放在檔案開頭，processTilt() 改成讀取設定。面板打開時不要擋住油門與倒退按鈕的觸控。
請加詳細中文註解，完成後告訴我怎麼確認成功。
```

**確認成功**：手機打開「⚙️ 手感」，把靈敏度切到「高」，輕輕傾斜就能看到 steer 接近 ±1；重新整理頁面後設定還在；比賽中轉向手感確實改變。

### 第 2 題：倒數時自動校正方向盤中心（🎯 陀螺儀 ★）

```
你是我的程式老師，我是初學者。請閱讀 game/public/js/controller.js 的「校正」按鈕（calibrationAngle）與收到 status 訊息的處理。
目前玩家要自己按「校正」，常常忘記，導致開跑時車子一直偏一邊。請改成：
1. 手機收到 status.state 變成 'countdown' 時，開始記錄接下來約 1.5 秒內的傾斜角度（rawTiltDeg），取平均值當作新的 calibrationAngle。
2. 如果這段時間角度變化太大（最大與最小相差超過 15 度，代表玩家正在亂晃），就不要自動校正，保留原本的中心。
3. 自動校正成功時，方向盤圖示下方顯示「✅ 已自動校正」1.5 秒；手動「校正」按鈕照樣保留。
4. 在大螢幕倒數時，手機畫面中央顯示「請把手機拿正」提示。
請加詳細中文註解，完成後告訴我怎麼確認成功。
```

**確認成功**：故意把手機歪 15 度拿著等開賽，倒數結束後車子能直直往前開，手機出現「✅ 已自動校正」；倒數時一直亂晃則不會自動校正。

### 第 3 題：分級震動回饋（🎯🎮 兼具 ★）

```
你是我的程式老師，我是初學者。請閱讀 game/public/js/network.js 的 game.on('playerHit')、game.on('miniTurbo')、game.on('wrongWay')，以及 controller.js 收到 {type:'vibrate'} 時的 triggerFeedback()。目前只有被打中、迷你加速、逆向時會震動。
請讓手機用「不同的震動節奏」告訴玩家車子發生什麼事：
1. 撞牆：中等震動 120ms（撞牆時 game 會發出 'wallHit' 事件，資料裡有 player，可以直接用 game.on 訂閱）
2. 開上草地：每 0.4 秒輕震 25ms，回到路面就停止（路面判斷可參考 car.js 的 isOffroad）
3. 甩尾集氣升級（藍→橘→紫）：每升一級震一下，等級越高震越長（40 / 60 / 90ms）
4. 吃到道具箱：兩下短震 [30, 40, 30]
讓 vibrate 訊息除了 ms 數字之外也接受陣列（navigator.vibrate 本身支援陣列節奏）。iPhone 不支援震動，維持畫面閃爍即可，但草地的輕震不要讓畫面一直閃。
同一種震動不要太頻繁送出（例如撞牆 0.5 秒內只送一次），避免塞爆網路。請加詳細中文註解，並為新事件補上自動測試。
```

**確認成功**：用 Android 手機玩：開上草地手機會一直輕輕震、撞牆時明顯震一下、甩尾火花變色時各震一下；`npm test` 全部通過。

### 第 4 題：起跑時搖手機催油門（🎯🎮 兼具 ★★）

```
你是我的程式老師，我是初學者。請閱讀 game/public/js/game.js 倒數（countdown）階段的起跑衝刺判定（lastPressTime、lastThrottle），以及 controller.js 的 handleDeviceMotion()。
請新增「搖手機催油門」起跑玩法：
1. 手機在倒數期間，用 devicemotion 的 acceleration（不含重力）計算搖晃強度，累積成 0～100 的「引擎轉速」，不搖時慢慢下降。手機畫面顯示一個轉速表，綠色區間在 60～80。
2. 手機把轉速數值（0～1）放在 input 訊息的新欄位 rev 送出；RemoteInput 與 getState() 要帶出這個欄位（沒有時當作 0，鍵盤玩家不受影響）。
3. 開賽瞬間轉速在綠色區間 → 獲得起跑衝刺（沿用 applyBoost 與 startBoostTime 角色加成）；超過 90 → 引擎過熱，和太早按油門一樣空轉 0.5 秒；其他 → 正常起步。
4. 原本「最後 1 秒按住油門」的起跑方式保留，兩種方式都能觸發衝刺。
把綠色區間、過熱門檻放到 config.js。請加詳細中文註解，並在 tests/ 補上起跑判定的測試。
```

**確認成功**：倒數時用力搖手機讓轉速停在綠色區間，開賽瞬間車子會衝出去；搖過頭會原地空轉；`npm test` 通過。

### 第 5 題：甩一下手機觸發甩尾（🎯🎮 兼具 ★★）

```
你是我的程式老師，我是初學者。目前甩尾要同時按住「油門」和「倒退」，有些玩家覺得很難按。請閱讀 game/public/js/controller.js 的 handleDeviceMotion() 與 network.js 的 RemoteInput（throttle > 0.5 且 brake > 0.5 時 drift = true），以及 car.js 的甩尾邏輯（需要速度 > DRIFT_MIN_SPEED 且轉向 > 0.3 才會開始甩尾）。
請新增「甩一下手機」開始甩尾：
1. 用 devicemotion 的 rotationRate 偵測手機像方向盤一樣快速轉動（角速度超過約 200 度/秒，數值抽成常數）。
2. 偵測到甩動、而且玩家正按著油門時，手機在 input 訊息加上 drift: true，並一直維持到玩家把手機轉回接近中間（傾斜 < 10 度）或放開油門為止；放開時就像放開甩尾鍵一樣釋放迷你加速。
3. RemoteInput 讀取這個 drift 欄位，和原本「油門＋倒退」的甩尾方式並存。
4. 手機設定裡加一個開關「甩動甩尾」，預設開啟，存在 localStorage。
請加詳細中文註解，並為 RemoteInput 的新欄位補上測試（tests/network.test.js）。
```

**確認成功**：開到高速時，快速把手機往一邊甩，車子開始甩尾並噴火花；轉回中間時獲得迷你加速；關掉開關後甩手機不會甩尾。

### 第 6 題：甩尾中用傾斜控制集氣速度（🎯🎮 兼具 ★★）

```
你是我的程式老師，我是初學者。請閱讀 game/public/js/car.js 的甩尾邏輯：甩尾中 into = steer * driftDir 會影響轉彎幅度，集氣是 driftCharge += dt * stats.driftChargeRate。
目前甩尾中怎麼傾斜，集氣速度都一樣，少了技巧性。請改成：
1. 甩尾中「往彎內傾斜」（into > 0.5）：轉得比較急，集氣速度 ×1.4
2. 「往彎外傾斜」（into < -0.2）：轉得比較緩，集氣速度 ×0.7
3. 介於中間：維持 ×1.0
4. 把倍率與門檻放到 config.js 並加中文說明。
5. 大螢幕的甩尾集氣條（hud.js 的 cell-drift-meter）在集氣加速時顯示「⚡ 內切加速」小字，讓玩家知道自己做對了。
6. 手機把集氣狀態也顯示出來：status 加上 driftLevel，手機方向盤圖示外圈依等級變成藍 / 橘 / 紫。
請加詳細中文註解，並在 tests/drift.test.js 補上內傾、外傾集氣速度的測試。
```

**確認成功**：甩尾時把手機往彎內壓，火花明顯比較快變成紫色；手機的方向盤外圈跟著變色；`npm test` 通過。

### 第 7 題：傾斜決定道具往前或往後丟（🎯🎮 兼具 ★★）

```
你是我的程式老師，我是初學者。請閱讀 game/public/js/items.js 的 useItem()、香蕉與導彈的生成方式，以及 controller.js 的道具按鈕（itemCounter）與 handleDeviceMotion()。
請讓玩家用手機前後傾斜決定道具方向：
1. 手機用重力的 z 分量估算前後傾斜（手機上緣往前倒 = 前傾），按下道具鈕的瞬間，把方向放進 input 訊息的新欄位 aim：前傾超過 20 度送 'front'、後仰超過 20 度送 'back'、其他送 'auto'。
2. RemoteInput 在 useItem 觸發時一併帶出 aim；game.js 呼叫 itemSystem.useItem(racer, aim)。
3. 香蕉：'front' 時往車頭前方拋出約 25 單位，'back' 或 'auto' 維持原本放在後方。
4. 導彈：'back' 時往後方直線發射（可以打後面追上來的車），'front' 或 'auto' 維持原本行為。
5. 手機按住道具鈕時，在按鈕上方顯示目前方向「⬆️ 往前丟」或「⬇️ 往後丟」。
```
